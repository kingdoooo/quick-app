# `contract/.venv` 的依赖清单。**这个 venv 被两个包共用**：contract 自己的测试，
# 以及 auth 的测试（auth 没有自己的 venv，借这个 —— `PyJWT` 与 `boto3` 就是为它
# 装的，CLAUDE.md「测试命令」那一节记着这条借用关系）。
#
# **只用于跑测试**，不进任何部署产物。
#
# 重建（**必须带 `--clear`**：shebang 是绝对路径，不带就一直报 bad interpreter；
# **必须在本目录下跑**——下面那条 `-e` 的相对路径是按**进程 cwd** 解析的，
# 不是按本文件的位置）：
#
#     cd site-builder/contract
#     python3 -m venv --clear .venv
#     .venv/bin/pip install -r requirements-dev.txt
#
# 版本为**精确钉死**（含传递依赖），与 `mcp/requirements.txt` 同一个思路：
# 宁可过度钉死，也不要「新机器解析出另一套依赖集合」这种查不动的差异
# （CLAUDE.md 记着这条：不同版本解析出的依赖集合与 marker 分支不同）。
# **不写 git remote 形态的可编辑安装行**（`pip freeze` 会输出它）——那会把仓库地址
# 钉进来；本地相对路径不依赖任何远端。
